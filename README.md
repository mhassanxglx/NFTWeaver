# NFTWeaver

Generates digital artifacts from user-defined templates using metadata from blockchain and file system APIs.

The key benefits of using NFTWeaver include:

- Generates digital artifacts from user-defined
- templates using metadata from blockchain
- and file system APIs

## Key Features

- Generates digital artifacts from user-defined
- templates using metadata from blockchain
- and file system APIs

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/NFTWeaver.git`
2. `cd NFTWeaver`
3. Install in editable mode: `pip install -e .`

## Configuration

NFTWeaver is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
